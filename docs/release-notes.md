# Notas de Lanzamiento (Release Notes)

## Preparación para la próxima versión (v1.2.1)

### Justificación del Versionado Semántico
Siguiendo las reglas de versionado semántico (MAJOR.MINOR.PATCH):
- **MAJOR (1):** No hay cambios incompatibles con la versión anterior.
- **MINOR (2):** No se han introducido nuevas funcionalidades en el código.
- **PATCH (1):** Se incrementa este valor respecto a la `v1.2.0` porque los últimos cambios introducidos son modificaciones menores y actualizaciones en la documentación (`docs: actualizar especificación de casos de uso`).
